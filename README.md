# Сервис учета кадровых заявлений

## Название проекта

**HR-Request Service** — сервис учета кадровых заявлений

## Назначение

Сервис предназначен для автоматизации процесса подачи, обработки и учета кадровых заявлений сотрудников организации. Система позволяет централизованно регистрировать заявления (на отпуск, перевод, увольнение, прием на работу и т.д.), отслеживать их статус, согласовывать с ответственными лицами и формировать отчетность по кадровым процессам.

Основные цели:

- снижение доли бумажного документооборота;
- ускорение обработки кадровых заявлений;
- прозрачность статусов и истории изменений;
- уменьшение количества ошибок при ручном вводе данных.

## Целевая аудитория

- **Сотрудники организации** — подача заявлений и отслеживание их статуса.
- **HR-специалисты и кадровая служба** — обработка, проверка и учет заявлений.
- **Руководители подразделений** — согласование заявлений подчиненных.
- **Администраторы системы** — управление пользователями, справочниками и правами доступа.

## Описание предметной области

Предметная область охватывает процессы кадрового делопроизводства, связанные с обработкой заявлений сотрудников. Кадровое заявление — это официальный запрос сотрудника, требующий регистрации, проверки, согласования и исполнения.

Жизненный цикл заявления включает этапы:

1. Создание и подача заявления сотрудником.
2. Регистрация заявления в системе.
3. Проверка HR-специалистом.
4. Согласование руководителем (при необходимости).
5. Принятие решения (одобрено / отклонено).
6. Исполнение и архивирование.

В процессе участвуют сотрудники, руководители, HR-специалисты и администраторы. Система должна обеспечивать разграничение прав доступа, хранение истории изменений и формирование отчетов.

## Основные сущности

| Сущность | Описание |
|---|---|
| **Пользователь** | Учетная запись сотрудника с ролью и правами доступа |
| **Сотрудник** | Физическое лицо, данные о должности, подразделении |
| **Подразделение** | Структурная единица организации |
| **Роль** | Набор прав доступа (сотрудник, руководитель, HR, администратор) |
| **Заявление** | Кадровый запрос с типом, статусом, датами и содержанием |
| **Тип заявления** | Категория (отпуск, перевод, увольнение, прием и т.д.) |
| **Статус заявления** | Текущее состояние (черновик, подано, на согласовании, одобрено, отклонено, исполнено) |
| **Согласование** | Запись о решении согласующего лица |
| **Комментарий** | Примечание к заявлению |
| **Вложение** | Прикрепленный файл (скан-копия, справка) |
| **История изменений** | Журнал действий по заявлению |

## Основные функции

- Регистрация и авторизация пользователей с разграничением ролей.
- Создание, редактирование и подача кадровых заявлений.
- Просмотр списка заявлений с фильтрацией и поиском.
- Согласование и отклонение заявлений руководителями и HR.
- Изменение статуса заявления и ведение истории действий.
- Добавление комментариев и вложений.
- Уведомления пользователей об изменении статуса заявления.
- Ведение справочников (типы заявлений, подразделения, должности).
- Формирование отчетов по кадровым заявлениям.
- Администрирование пользователей и прав доступа.

## План развития проекта

### Этап 1. MVP

- Реализация базовой модели данных (пользователи, заявления, статусы).
- Авторизация и разграничение ролей.
- Создание и просмотр заявлений.
- Простой workflow согласования.

### Этап 2. Расширение функциональности

- Уведомления (email, внутренние).
- Вложения и комментарии.
- Расширенные фильтры и поиск.
- История изменений заявлений.

### Этап 3. Аналитика и отчетность

- Дашборды по кадровым процессам.
- Экспорт отчетов (Excel, PDF).
- Статистика по типам и статусам заявлений.

### Этап 4. Интеграции

- Интеграция с 1С:ЗУП и другими HR-системами.
- REST API для внешних сервисов.
- Интеграция с корпоративным мессенджером.

### Этап 5. Развитие и масштабирование

- Мобильное приложение.
- Электронная подпись документов.
- Автоматизация маршрутов согласования.
- Поддержка мультиязычности и мультитенантности.
