# Сервис учета кадровых заявлений (Application Track Service)

## Назначение

Приложение **HR-Request Service** предназначено для автоматизации процесса подачи, регистрации и обработки кадровых заявлений сотрудников организации. Программа позволяет централизованно учитывать заявления (на отпуск, перевод, увольнение, прием на работу), присваивать им уникальный номер, определять статус и сохранять основные сведения о заявителе.

Текущая версия — консольное приложение, реализующее полный цикл работы с сотрудниками и их заявлениями: просмотр, добавление, поиск, сортировка, отмена заявлений и вывод статистики. Данные хранятся в JSON-файлах.

## Целевая аудитория

- **Сотрудники организации** — подача заявлений и отслеживание их статуса.
- **HR-специалисты и кадровая служба** — регистрация, проверка и обработка заявлений.
- **Руководители подразделений** — согласование заявлений подчиненных.
- **Администраторы системы** — управление пользователями и справочниками.

## Предметная область

Предметная область охватывает процессы кадрового делопроизводства, связанные с обработкой заявлений сотрудников. Кадровое заявление — это официальный запрос сотрудника, требующий регистрации, проверки, согласования и исполнения.

Жизненный цикл заявления включает этапы:

1. Создание и подача заявления сотрудником.
2. Регистрация заявления в системе.
3. Проверка HR-специалистом.
4. Согласование руководителем.
5. Принятие решения (одобрено / отклонено).
6. Исполнение и архивирование.

## Основные сущности

- **Сотрудник** — ID, ФИО, подразделение, возраст.
- **Заявление** — уникальный номер, дата подачи, тип, статус, ссылка на сотрудника.
- **Тип заявления** — отпуск, перевод, увольнение, прием на работу.
- **Статус заявления** — на согласовании у руководителя / HR, на регистрации, отклонено, требует доп. проверки.
- **Подразделение** — структурная единица организации.

## Установка

1. Клонируйте репозиторий или скопируйте папку проекта.
2. Перейдите в каталог проекта:
   ```bash
   cd ApplicationTrackService
   ```
3. Установите зависимости:
   ```bash
   python -m pip install -r requirements.txt
   ```

## Запуск

Запустите приложение из корня проекта:

```bash
python main.py
```

Откроется консольное меню:

```

1. Показать сотрудников
2. Добавить сотрудника

4. Создать заявление

6. Найти заявления
7. Отменить заявление

9. Статистика
```

## Основные функции

### `employees.py`

- **`get_next_employee_id(employees)`** — возвращает следующий свободный ID сотрудника.
- **`add_employee(employees, employee_id, fio, department, age)`** — добавляет нового сотрудника в список.
- **`find_employees(employees, query)`** — ищет сотрудников по ФИО или подразделению.
- **`show_employees(employees)`** — выводит список сотрудников на экран.
- **`sort_employees_by_age(employees)`** — сортирует сотрудников по возрасту.

### `requests.py`

- **`get_type_and_status(choice, age)`** — по номеру типа заявления и возрасту сотрудника определяет тип заявления и его начальный статус (с проверками возраста).
- **`get_next_request_id(requests)`** — возвращает следующий свободный номер заявления.
- **`create_request(requests, employees, employee_id, choice)`** — создаёт новое заявление для сотрудника.
- **`cancel_request(requests, request_id)`** — удаляет заявление по номеру.
- **`find_requests(requests, employees, query)`** — ищет заявления по ФИО, типу или статусу.
- **`sort_requests(requests, sort_choice)`** — сортирует заявления по дате, типу или статусу.
- **`get_request_statistics(requests)`** — формирует статистику заявлений по типам.
- **`show_requests(requests, employees)`** — выводит заявления на экран.

### `storage.py`

- **`load_json(filename, default)`** — загружает список из JSON-файла.
- **`save_json(filename, data)`** — сохраняет список в JSON-файл.
- **`load_employees(filename)` / `save_employees(filename, employees)`** — загрузка и сохранение сотрудников.
- **`load_requests(filename)` / `save_requests(filename, requests)`** — загрузка и сохранение заявлений.

### `utils.py`

- **`input_non_empty(prompt)`** — безопасный ввод непустой строки.
- **`input_int(prompt, min_value, max_value)`** — безопасный ввод целого числа с проверкой диапазона.
- **`input_choice(prompt, choices)`** — ввод одного значения из набора допустимых вариантов.

## Тестирование

В проекте используются тесты на `pytest`. Запуск:

```bash
python -m pytest
```

Или просто:

```bash
pytest
```

Тесты покрывают:
- работу с сотрудниками (`tests/test_employees.py`);
- работу с заявлениями (`tests/test_requests.py`).

## Форматирование кода

Для проверки стиля используется `flake8`:

```bash
flake8 .
```

## Данные

Все данные хранятся в папке `data/` в формате JSON:

- `data/employees.json` — список сотрудников.
- `data/requests.json` — список заявлений.

Файлы создаются автоматически при первом сохранении, если их нет.
