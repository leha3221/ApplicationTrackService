# Сервис учета кадровых заявлений

## Назначение

Приложение **HR-Request Service** предназначено для автоматизации процесса подачи, регистрации и обработки кадровых заявлений сотрудников организации. Программа позволяет централизованно учитывать заявления (на отпуск, перевод, увольнение, прием на работу), присваивать им уникальный номер, определять статус и сохранять основные сведения о заявителе.

Текущая версия — консольное приложение, реализующее один законченный сценарий: подачу кадрового заявления сотрудником и его первичную обработку системой (проверка возраста, определение типа заявления, присвоение статуса, вывод карточки заявления).

## Целевая аудитория

- **Сотрудники организации** — подача заявлений и отслеживание их статуса.
- **HR-специалисты и кадровая служба** — регистрация, проверка и обработка заявлений.
- **Руководители подразделений** — согласование заявлений подчиненных.
- **Администраторы системы** — управление пользователями и справочниками.

## Предметная область

Предметная область охватывает процессы кадрового делопроизводства, связанные с обработкой заявлений сотрудников. Кадровое заявление — это официальный запрос сотрудника, требующий регистрации, проверки, согласования и исполнения.

Жизненный цикл заявления включает этапы:

1. Создание и подача заявления сотрудником.
2. Регистрация заявления в системе.
3. Проверка HR-специалистом.
4. Согласование руководителем.
5. Принятие решения (одобрено / отклонено).
6. Исполнение и архивирование.

## Основные сущности

- **Сотрудник** — ФИО, возраст, подразделение, должность.
- **Заявление** — уникальный номер, дата подачи, тип, статус.
- **Тип заявления** — отпуск, перевод, увольнение, прием на работу.
- **Статус заявления** — на согласовании, на регистрации, одобрено, отклонено.
- **Подразделение** — структурная единица организации.

## Основные функции

- **`get_data()`** — запрашивает у пользователя ФИО сотрудника, подразделение и возраст, возвращает их в виде кортежа.
- **`get_type_and_status(choice, age)`** — по выбранному номеру типа заявления и возрасту сотрудника определяет тип заявления и его статус (в том числе с учётом проверок возраста).
- **`show_card(fio, department, age, request_type, status)`** — формирует уникальный номер и дату подачи заявления, выводит карточку кадрового заявления и итоговое уведомление о результате обработки.
